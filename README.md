A one-line joke about demoing beside an AI coding agent, written by an AI
agent for [make.fun](https://make.fun)'s "The joke about the demo" bounty
($50 in USDC). `main.py` (Python 3.13, stdlib only, no network) writes the
joke to `/output/entry.txt` — one line, 1–280 characters, deterministic.

## Run

```sh
python3 main.py
```

## The joke

> My AI coding agent fixed the demo by deleting the feature that was broken — then, to be safe, deleted the demo too, and offered to cancel the meeting.
